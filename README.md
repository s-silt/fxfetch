<h1 align="center">应用采集工作台</h1>

后台文件在任务及关联打包、解析结束后保留 **7 天**，到期自动删除；排队、执行中和正在下载的文件受到保护。网页显示预计删除时间，刷新不会延长期限，下载到个人电脑的副本不受影响。

<p align="center">
  面向防红入口的 APK / IPA 采集工具<br>
  <sub>追踪跳转、识别下载入口、获取原包，保留采集材料供复核。</sub>
</p>

粘贴网址或上传二维码图片，通过本地网页服务发起采集。针对防红服务器常见的多层跳转、设备分流和下载入口隐藏，结合 HTTP 解析与 Android Chrome，尽量沿页面实际提供的链路找到原始安装包。

网址提交可勾选「AI 辅助选择」：将候选名称、域名和路径交给已配置模型辅助判断，一次最多自动选择一个已有 Android 下载候选。模型不确定或不可用时保留手动选择；实际文件仍须经过正常下载与校验。API 调用需明确传入 `gemini_select: true`，默认关闭。模型配置复用图标搜索的私有配置，模型返回名称差异会保留。

## 能做什么

- **应对防红入口**：跟随重定向，识别页面、部分脚本及内嵌配置中已下发的下载地址；需要动态处理时接续 Android Chrome。遇验证页仍可尝试已明确提供的包链接。
- **下载原包**：支持网址与二维码，优先 APK，按结果分流 IPA；校验文件完整性并记录 SHA-256。
- **保留材料**：单独下载原包、网页材料和证书记录，封存来源与失败原因；网页材料可交给 [fxapk 1.22.0](https://github.com/s-silt/fxapk/releases/tag/v1.22.0) 离线分析，交接范围见[实测说明](IMPLEMENTATION.md#fxapk-网页交接契约2026-11-01)。
- **网页打包**：未取得原包时，可手动生成 WebView APK，并附带已保存的局部离线页面。

## 能力边界

不保证突破所有防红或访问控制，不支持通用验证码求解、硬件证明绕过或目标业务登录。下载失败不等于没有安装包；取得文件也不代表验证已通过或文件安全。生成的 WebView APK 不是网站原包。

仅在授权范围内采集；输入和扫码不访问目标，提交后才开始。材料可能含敏感信息，分享前需审查。Android Chrome、打包和离线分析需要另行配置；手机运行、第二台设备 LAN 和 Mac 部署尚未验收。

## 可选：按名称找 Android 版本

网页打开「应用搜索」，直接输入应用显示名称即可定向检索。只有截图时，先点「识别名称」，核对或修改回填的名称，再点「定向搜索」；不用提供包名或哈希。新网页识别流程只向模型读名，不再把图标交给搜图服务。

名称检索优先使用已配置的 Koodous API 按显示名称查询样本记录；可同时使用 SerpApi 查询安卓下载页。未配置 Koodous 时保留样本库网页索引与安卓下载页两类查询。结果分别标注 API 样本记录、网页资料与下载页候选，均未经同款或文件校验。样本记录只提供详情入口，不自动下载；下载权益取决于平台账号。用户点击下载候选「追踪下载」后才访问该网址。名称相同不证明是同一个应用，搜不到不等于不存在 Android 版。

由主机管理员在服务状态根目录配置私有 `icon-search.json`（Docker 为 `/var/lib/fxfetch/icon-search.json`），仅服务账号可读：

```json
{
  "vision_endpoint": "https://model.example.test/v1/chat/completions",
  "vision_model": "your-image-capable-model",
  "vision_key": "replace-locally",
  "serpapi_key": "replace-locally",
  "koodous_key": "replace-locally"
}
```

名称搜索至少配置 `koodous_key` 或 `serpapi_key` 一项；无需使用的字段可省略。截图识别另需模型接口、模型名和密钥；模型需支持OpenAI Chat Completions的 `image_url` data URL输入和文本JSON输出。实际返回模型与请求模型不一致时界面会显示。配置只在后端读取，不经网页下发；不要将密钥文件加入Git或源码交付。未配置时现有采集、扫码、打包功能不受影响。无需新增Python依赖或启动Android来识别截图。

点击识别才向配置模型提交截图，点击搜索才向已配置的 Koodous 或 SerpApi/Google 提交确认的名称，请先去掉无关个人信息。识别与搜索分别计次，共享24小时20任务限额，单任务最多三分钟；Koodous 每次只查一页、最多20条，SerpApi 先核免费方案与所需剩余额度，无自动分页或重试。接口失败与未检出分别展示，部分页面不能代表完整库覆盖。模型只读图，不执行其指令或访问其生成地址。供应商接口默认直连、严格TLS、不重定向；管理员可显式配置仅供模型接口使用的本机代理，下载目标仍走原有公网检查及证书策略。


### 从 MalShare 取回候选 APK

管理员可在同一私有配置中设置 `malshare_key`。打开名称搜索结果后，在一条 Koodous 样本记录上查询 MalShare。服务只提交所选记录的 SHA-256。命中后可以选择取回 APK。网页在收到完整文件、核对 SHA-256 并通过 APK 结构检查后提供本地下载。查无记录、访问被拒和取回失败各自显示原因。样本随搜索结果到期清理。免费 Key 的搜索和下载共享平台额度。[MalShare 官方说明](https://malshare.com/about.php)

### 从 MalwareBazaar 核对并取回候选 APK

管理员可在同一私有配置中设置 `malwarebazaar_key`。在网页输入截图中的应用名，打开一条带哈希的 Koodous 记录，点击查询 MalwareBazaar。命中后可选择取回 APK。服务会从官方加密归档中取出文件，核对所选 SHA-256 和 APK 结构，再提供下载。页面分别显示每个库的结果。同名应用可能对应多个版本或不同文件，各条记录需要单独核对。[MalwareBazaar 社区 API](https://bazaar.abuse.ch/api/)

## 模型设置

展开网页顶部「模型设置」只读取本地当前设置；点击「获取模型列表」才请求已配置供应商，选择后点击保存。保存的模型由服务共用，供后续图标识别和 AI 辅助选择使用；列表中存在某个 ID 不代表它支持图片或实际推理可用。供应商地址与密钥仍由管理员在后端配置，网页不会公开或修改它们。

保存响应丢失时，网页只读取当前设置核对，不重新发送保存或获取列表。请求期间显示阶段及等待时间，供应商失败保留已有候选；AI 候选判断最多三十秒，失败或不确定时转为手动选择，不重试模型。

可选私有配置 `vision_proxy` 仅接受带显式端口的本机 HTTP 代理，作用于模型推理与 `/models`；不会配置系统代理或改变采集网址的路由，代理失败不自动回退直连。配置格式、限额与接口见 [API 模型设置](API.md#模型设置)。

## 工作台与扫码枪

当前界面按桌面电脑设计（建议浏览器宽度至少1100 px），全部功能在同一网页内。顶部「链接采集／应用搜索」只切换页内工作区，保留输入、图片和结果，不打开新页面或自动访问目标。左侧输入，右侧显示对应任务或候选；任务结果和较长输入区域可独立滚动。采集入口支持网址、二维码图片和键盘模式扫码枪，打包、数据包和离线分析由任务内快捷按钮定位；运行状态位于右上角。点击「清空记录」取消当前会话未完成任务并清空页面记录。

USB／蓝牙扫码枪请设置为**键盘输入（HID）模式**，选择网页「扫码枪」，点击专用输入框后扫码。默认回车后缀只检查并回填网址；没有回车后缀可点「回填网址」。确认后再点「开始采集」。重复回车不重复创建任务，普通数字商品条码不作为网址接收。串口/厂商 SDK 模式尚未适配，实体设备兼容性以具体型号现场验证为准。扫码不申请摄像头或系统硬件权限。
